# Tweede Kamer motions sample

Motions published by the Dutch House of Representatives as open data (CC0 1.0 in the data.overheid.nl catalogue). See `source.json` for provenance. Read the portal's own disclaimer before redistributing.

CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/ (the dedication needs no attribution; the source is named as a courtesy).

The table and its sentence embeddings are published as the `data-v1` release assets and restored when the site is built, not stored in git; see docs/data-and-assets.md.
