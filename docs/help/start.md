# Help and shortcuts

Explore a table locally, highlight interesting records, and build maps or themes when you need them.

## First steps

1. Import a spreadsheet, CSV, JSON or SAV table, or choose an example (the examples open with a precomputed map and named clusters).
2. Inspect columns and a few records. Correct column types if necessary.
3. Brush a chart or type a query to highlight records.
4. Read [phrases and metadata facets](descriptions.md) describing the current population.
5. Use [similarity maps](maps.md) and [clustering](clustering.md) to explore patterns.

## Example

Highlight a group of records, inspect their distinctive phrases, and click one to add a condition to your query.

## Learning path

- [Highlight and filter](selection.md): brush, query, and commit a filter.
- [Make a map](maps.md): choose columns and a representation.
- [Choose a text model](text-models.md): language, context and long text.
- [Combine fields](combining.md): averages, variable groups and weights.
- [Find themes](clustering.md): review clusters and compare groups.
- [Inspect and export](data.md): types, annotations and saved results.

## Shortcuts

- Brush or tap replaces the highlight; Shift adds; Alt/Option intersects.
- Table Ctrl/Cmd-click toggles a record; Shift-click selects a range.
- Enter applies a query preview. Incomplete queries keep the last valid highlight.
- Escape closes the top dialog or cancels an active card/divider drag.
- Arrow keys resize a focused divider. Double-click resets that divider.

## Troubleshooting

Nothing is uploaded; runtime and model assets load locally, and analysis uses CPU/WASM.

Export your work before closing: this workspace is held in memory, and exports are not a reloadable project.
